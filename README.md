# Information Architecture & Wireframes: IRCTC Train Booking Redesign

## 1. Project Overview
* **Product:** IRCTC Train Ticket Booking App & Web Flow (Continuation of Milestone 2 Research & Audit)
* **Goal:** Restructure the cluttered navigation into a clean, task-first Information Architecture (IA) and design low-fidelity wireframes that simplify train search, seat selection, and passenger checkout.
